## Maintenance

Before adding a lesson:

1. Check whether the rule already exists in `AGENTS.md`, `.ai/rules/`, or `CONTEXT.md`.
2. Add it only if it captures a recurring pitfall or durable project-specific insight.
3. Merge duplicates instead of appending near-identical entries.
4. Remove lessons that become obsolete or are promoted into canonical project rules.
